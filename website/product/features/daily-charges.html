日々の自費記録・品目マスタ

介護サービスや日用品などの自費項目を日別に記録し、品目をマスタ管理して請求に連携します。
入居者ごとの自費サービスを漏れなく記録し、正確な請求データを生成します。

こんな課題ありませんか？

自費記録が手書きやExcelで煩雑

日々の自費サービス（おやつ・日用品・理美容等）を記録する際に、
手書きノートやExcelで管理しているため、記録漏れや転記ミスが発生しやすい。

品目ごとの単価管理が一貫していない

同じ自費サービスでも、担当者によって単価が異なる場合があり、
請求金額にばらつきが生じて施設内でのサービス提供に不公平が生じる。

月末の請求処理に時間がかかる

散らかった自費記録を月末に集計し、請求データに反映する作業に
時間がかかり、請求締め日が遅れがちになる。

あんしんの解決方法

日々の自費記録をデジタル化し品目をマスタ管理

タブレットやPCで日々の自費サービスを記録し、品目・単価・税区分をマスタで管理。
記録したデータは自動的に月次請求に連携され、請求書に反映されます。

「自費記録」メニュー → 「＋ 新規記録」 → 入居者選択 → 品目選択 → 数量入力 → 「登録」

品目マスタ管理

一元管理された品目マスタで統一されたサービス提供

自費サービスの品目（おやつ・日用品・理美容・クリーニング等）とその単価・税区分を
マスタで一元管理し、施設全体で同じサービスに対して同じ単価が適用されます。

品目マスタの項目

  • ● 品目コード（管理用ID）
  • ● 品目名称（表示名）
  • ● 単価（税抜または税込）
  • ● 税区分（非課税・課税10%・課税8%）
  • ● 有効期間（開始日・終了日）
  • ● 備考（適用条件等）

マスタ運用のメリット

  • ● 単価の間違い防止
  • ● 新規品目の追加が簡単
  • ● 廃止品目の自動除外
  • ● 過去の記録も参照可能（品目名・単価の履歴保持）

自費記録の操作フロー

シンプルな記録プロセスで毎日5秒の入力を実現

  1. 記録時間選択：デフォルトで現在時刻（任意で変更可能）
  2. 入居者選択：施設内の入居者から選択（フリガナ検索対応）
  3. 品目選択：マスタから品目を選択（よく使う品目は優先表示）
  4. 数量入力：デフォルト「1」（必要に応じて変更）
  5. 記録完了：ボタン一つで記録を保存し、自動で請求データに連携

請求処理への自動連携

記録データが自動的に月次請求に反映

日々記録された自費データは、自動的に対象月の請求データに蓄積されます。
月次請求一括生成時に、家賃・管理費と同様に自費合計が計算され、請求書に含まれます。

請求連携の仕組み

  • ● 記録日が属する月の請求データに紐付け
  • ● 品目マスタの単価と数量から金額を自動計算
  • ● 税区分に応じて消費税を自動計算
  • ● 請求書および領収書PDFに自費内訳を明示

請求書への反映例

【内訳】 基本家賃： 50,000円 管理費： 10,000円 自費合計： 1,500円 ○ おやつ（300円×2日）： 600円 ○ 日用品（500円×1日）： 500円 ○ 理美容（400円×1日）： 400円 消費税： 1,150円 合計： 62,650円
