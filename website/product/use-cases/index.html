ユースケース

施設の規模やサービス形態に応じたあんしんの活用事例をご紹介します。
小規模施設から大規模施設・法人まで、様々なニーズに対応するプランをご用意しています。

施設規模・サービス形態別ユースケース

小規模施設向け

小規模施設向けプラン

定員10床以下の小規模施設向けに、必要十分な機能を低コストで提供するプランです。
グループホームや小規模多機能型居宅介護事業所などに最適です。

詳細を見る
中規模施設向け

中規模施設向けプラン

定員11～30床の中規模施設向けに、拡張性とコストパフォーマンスを両立したプランです。
特別養護老人ホームや介護老人保健施設などに最適です.

詳細を見る
大規模施設・法人向け

大規模施設・法人向けプラン

定員31床以上の大規模施設および複数施設を運営する法人向けに、法人レベルでの一元管理と高度な分析機能を提供するプランです.

詳細を見る
ショートステイ・日中サービス対応

ショートステイ・日中サービス対応プラン

ショートステイや日中サービス（通所介護等）を提供する施設向けに、
利用日数に応じた柔軟な請求処理と、様々なサービス形態に対応した機能を提供するプランです.

介護付き有料老人ホーム向け

介護付き有料老人ホーム向けプラン

介護付き有料老人ホーム向けに、入居一時金・月額利用料の請求、介護サービスと生活支援サービスの別々請求、入退去管理などをサポートするプランです.

施設に最適なプランの選び方

施設の規模とニーズに合わせてプランを選択

  1. 施設の定員を確認：10床以下なら小規模施設向け、11～30床なら中規模施設向け、31床以上なら大規模施設・法人向けプランを検討
  2. 提供サービスを確認：ショートステイや日中サービスを提供しているか、介護付き有料老人ホームかどうかを確認
  3. 将来の展開を考慮：施設の拡張や複数施設化を見据えて、アップグレード可能なプランを選択
  4. 無料デモで体験：実際の画面を体験しながら、施設の実務に合っているかを確認

施設に最適なプランを見つけましょう

まずは無料で資料をダウンロードし、各プランの詳細をご確認ください。施設の規模やご希望に合わせたお見積りもご用意しています.
