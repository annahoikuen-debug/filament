## 1. プロジェクト概要

### 1.1 システム概要

| 項目 | 内容 |
| --- | --- |
| システム名 | 高齢者施設請求管理システム「あんしん」 |
| バージョン | v1.0 "あんしん"（2026-10-07） |
| 技術スタック | PHP 8.2+ / Laravel 12 / Filament v3 / dompdf / SQLite（開発）・MySQL（本番） |
| 管理画面URL | `http://localhost:8000/admin`（開発環境） |
| アクセス権限 | `is_admin = true` のユーザーのみ |
| 初期アカウント | `admin@care-himawari.example.jp` / `password` |
| テスト | Pest（109テスト / 862アサーション通過） |

### 1.2 システムが提供する機能

1. **入居者管理** — 部屋番号・氏名・基本家賃・基本管理費・入居/退去日・ステータス
2. **自費品目マスタ** — 家賃・管理費以外の請求品目とデフォルト単価の管理
3. **日々の自費記録** — 日付 × 入居者 × 品目 × 単価 × 数量の利用記録（在籍期間バリデーション付き）
4. **月次請求データ一括生成** — 固定費の日割り計算 + 自費記録合算（`InvoiceCalculationService`）
5. **PDF発行** — 請求書・領収書の個別PDF、月次一括ZIP（`InvoicePdfService`）
6. **CSVエクスポート** — 会計仕訳連携用CSV / 請求一覧台帳CSV（`InvoiceCsvExportService`）
7. **入金管理** — 入金消込、ステータス遷移（未請求 → 請求済 → 入金済）、領収書番号自動発行

### 1.3 対象読者と目的

- **対象**: 施設の事務職員・介護職員（PCの基本操作ができる方）。プログラミング知識は不要。
- **目的**: 日常業務（入居者登録 → 自費記録 → 月次請求 → PDF発行 → 入金消込 → 領収書発行 → 会計連携）を、他者に頼らず正確に実施できること。
- **スコープ**: 管理画面の全メニュー、月次業務フロー、よくある質問（Q&A）、用語集。
- **アウトオブスコープ**: システム開発・サーバー構築・プログラム修正（開発者向け文書は README.md / DEPLOYMENT.md に分離）。

## 3. 画面図・イラスト方針

### 3.1 方針

- 本環境では実画面のキャプチャが取得できないため、**実画面を再現したSVGモックアップ**を図版として同梱する。
- モックアップは Filament v3 の実際のUI（サイドバー・テーブル・バッジ・アクション）を忠実に再現。
- 業務フロー・ステータス遷移は **Mermaid**（Markdown内蔵描画）と **SVG** の両方で提供。
- 将来的に実画面キャプチャを取得できる環境になった場合、SVGを差し替えるだけで済むよう、マニュアル本文は画像参照（パス）で記述する。

### 3.3 実画面キャプチャへの差し替え手順（将来用）

1. 管理画面にログインし、該当ページを表示
2. ブラウザのキャプチャ（Windows: `Win + Shift + S`）で画面を取得
3. `docs/assets/` の同名SVGをPNG等で置換
4. マニュアル本文の画像参照パスは変更不要（ファイル名を揃える）
