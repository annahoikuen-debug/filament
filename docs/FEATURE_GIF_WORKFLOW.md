# 機能説明GIF 24個 作成ワークフロー

## 目的
サンプルデータ（定員25名の施設・2026年10月分請求）を使い、システムの主要機能を説明するアニメーションGIFを24個作成し、製品紹介サイトに組み込む。

## ワークフロー

```
[1] 計画
    └─ docs/FEATURE_GIF_IMPLEMENTATION_PLAN.md（詳細実装計画書）を作成
        ├─ 24機能の選定（カテゴリ別: 入力/請求/PDF/CSV/管理）
        ├─ 各GIFのシナリオ（フレーム構成）定義
        └─ 出力仕様（サイズ・fps・色数）定義

[2] 生成基盤の実装
    └─ scripts/generate_feature_gifs.php（単一PHPスクリプト）
        ├─ GD拡張でフレーム画像を動的レンダリング
        ├─ 日本語テキスト描画（Noto Sans JP / IPAフォント使用）
        ├─ 疑似UI画面（ダッシュボード・フォーム・表）をコードで描画
        └─ imagettftext + imagegif でアニメーションGIF書き出し

[3] 生成実行
    └─ php scripts/generate_feature_gifs.php
        └─ website/assets/gifs/*.gif に24個出力

[4] 検証
    ├─ 24個すべて存在 & ファイルサイズ > 0 を確認
    ├─ GIFアニメーション形式の妥当性確認
    └─ サイズ過大(>1MB)の個別最適化

[5] 組み込み
    └─ website/product/features/*.html に <img> タグでGIFを配置

[6] 完了報告
```

## GIF共通仕様
| 項目 | 値 |
|------|-----|
| サイズ | 480x360 px |
| フレーム数 | 8〜12 フレーム/個 |
| フレーム遅延 | 40〜70 (100ms単位=0.4〜0.7秒) |
| ループ | 無限 |
| 色数 | 128色パレット |
| フォント | Noto Sans JP（storage/fonts または IPAex） |

## 24機能リスト（カテゴリ別）

### A. 入力系 (6個)
1. 入居者マスタ登録
2. 消耗品费用の毎日入力（スマホ）
3. 介護保険費用の入力
4. 定期課金の設定
5. 料金履歴管理
6. 一括データ取り込み（CSV）

### B. 請求計算系 (6個)
7. 月次請求書の一括生成
8. 税率計算（10%/8%/非課税の自動判別）
9. 入居日割り計算（月途中入退居）
10. 施設別フィルタ請求
11. 請求書の再計算・更新
12. 未収金アラート

### C. PDF出力系 (6個)
13. 個別請求書PDF
14. 領収書PDF
15. 一括ZIPダウンロード
16. カテゴリ別ZIP出力
17. パスワード保護PDF
18. QRコード（振込用）

### D. 管理・その他系 (6個)
19. ダッシュボード概要
20. CSV会計連携出力
21. 請求書統合（同居家族）
22. チャットボット照会
23. 複数施設管理
24. テンプレート設定

## 各GIFのシナリオパターン
- **type=tutorial**: 手順表示（ステップ1→2→3が順に出現）
- **type=dashboard**: 数値カウントアップ + ハイライト移動
- **type=form**: フォーム項目がタイピング風に埋まる
- **type=list**: 行データが順次追加/強調
- **type=flow**: フロー図の矢印が点灯していく
